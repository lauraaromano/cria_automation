# Casos de Teste — Logout

## TC01 — Realizar logout com sucesso

**Pré-requisito:**

* Usuário cadastrado.
* Usuário possui credenciais válidas.
* Usuário está autenticado na aplicação.

**Passos:**

1. **Pré-requisito:** Realizar login com um e-mail e senha válidos.
2. **Passos:** Validar que o usuário está autenticado.
3. Realizar o logout através da opção disponível na aplicação.

**Resultado esperado:**

* O login é realizado com sucesso.
* O usuário é identificado como autenticado.
* O sistema encerra a sessão do usuário com sucesso.
* O usuário deixa de ter acesso à área autenticada da aplicação.
