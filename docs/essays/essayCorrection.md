# Casos de Teste — Correção de Redação

## TC01 — Salvar uma redação dissertativa sem correção detalhada

**Pré-requisito:**

* Usuário cadastrado.
* Usuário possui credenciais válidas.
* Usuário está autenticado na aplicação.
* Uma redação dissertativa válida está disponível para teste.

**Passos:**

1. Acessar a área de criação de redação.
2. Selecionar o vestibular.
3. Selecionar um tema de redação do ENEM.
4. Selecionar o tipo de texto **"Dissertativo"**.
5. Selecionar o gênero textual **"Dissertativo-argumentativo"**.
6. Informar um título válido para a redação.
7. Informar o texto de uma redação dissertativo-argumentativa válida.
8. Realizar a validação da redação utilizando a IA.
9. Validar a mensagem **"Redação salva com sucesso"**.
10. Validar a mensagem **"Redação validada com sucesso"**.
11. Atribuir a nota máxima à redação.
12. Selecionar a opção para enviar a redação **sem correção detalhada**.
13. Finalizar o fluxo de envio da redação.

**Resultado esperado:**

* A redação é criada corretamente.
* O tipo de texto **"Dissertativo"** é aceito.
* O gênero textual **"Dissertativo-argumentativo"** é aceito.
* O título da redação é aceito.
* O texto da redação é aceito.
* A redação é salva com sucesso.
* O sistema apresenta a mensagem **"Redação salva com sucesso"**.
* A redação é validada com sucesso.
* O sistema apresenta a mensagem **"Redação validada com sucesso"**.
* A redação recebe a nota máxima.
* O sistema permite enviar a redação sem correção detalhada.
* O fluxo de envio da redação é concluído com sucesso.
