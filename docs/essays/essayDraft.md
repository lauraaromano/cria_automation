# Casos de Teste — Rascunhos de Redação

## TC01 — Salvar um rascunho de uma redação dissertativa com sucesso

**Pré-requisito:**

* Usuário autenticado no sistema.
* Usuário está na tela de criação de redação.
* Existe um tema disponível para redação dissertativa.
* Existe uma redação dissertativo-argumentativa válida para preenchimento.

**Passos:**

1. Clicar em "Criar Redação".
2. Selecionar o vestibular "Enem".
3. Selecionar um tema de redação disponível.
4. Selecionar o tipo de texto "Dissertativo".
5. Selecionar o gênero textual "Dissertativo-argumentativo".
6. Preencher o título da redação.
7. Preencher o texto da redação.
8. Salvar as informações de tema e gênero.
9. Clicar em "Salvar rascunho".
10. Retornar para a tela principal.
11. Acessar a aba "Rascunhos".

**Resultado esperado:**

* A redação dissertativa é preenchida corretamente.
* O rascunho é salvo com sucesso.
* O sistema exibe a mensagem "Redação salva com sucesso".
* O usuário consegue acessar a aba "Rascunhos".
* O rascunho salvo fica disponível na listagem de rascunhos.
